# Drills 66–81 — Bank, break, jump, bài kiểm tra

Quy ước toạ độ và ký hiệu nằm ở [00-index.md](00-index.md). File nguồn bank/kick/break dùng hệ (x, y) với y tính từ băng dưới. Em đổi L = x, W = y nên layout bị lật gương so với hình gốc, cách đánh không đổi.

Các bài 74–81 là bài chạy bàn. Sơ đồ chỉ đánh dấu chỗ đặt rack (`R`) và bi cái (`C`), không vẽ từng bi.

### 66 · B1 Cross-Side Bank

**Hạng E** · Bank một băng vào lỗ giữa · Billiard University Exam II, S7 Bachelors

```text
      0   1   2   3   4   5   6   7   8  L
     @----+---+---+---@---+---+---+----@
  W0 |                                 |
     |                                 |
  W1 |                                 |
     |                                 |
  W2 |        .32 1   .       .        |
     |                                 |
  W3 |                                 |
     |                                 |
  W4 |                                 |
     @----+---+---+---@---+---+---+----@
```

Toạ độ (L, W) → app (x, y): `1` (3, 2) → app (0.5, 0.625) · `2` (2.6, 2) → app (0.5, 0.675) · `3` (2.2, 2) → app (0.5, 0.725)

**Đặt bi:** ba bi trên trục giữa bàn (W = 2): bi 1 ở (3, 2), bi 2 ở (2.6, 2), bi 3 ở (2.2, 2), cách nhau 1 bi. Mỗi cú chỉ để một bi trên bàn. Bi cái ball in hand.

**Cách đánh:** bank bi mục tiêu bật long rail trái (W = 0) vào lỗ giữa SR. Chọn chỗ đặt bi cái sao cho không bị double kiss.

**Đạt khi:** 1 điểm mỗi bi vào, tối đa 3 [nguồn]. Hạng E đạt 2/3 [đề xuất].

**Nguồn:** https://billiarduniversity.org/documents/BU_Exam-II_Skills-Bachelors.pdf — layout và điểm [nguồn].

     @----+---+---+---@---+---+---+----@

     |                                 |

     |                                 |
  W4 |                                 |
     @----+---+---+---@---+---+---+----@
```

Toạ độ (L, W) → app (x, y): `x` (3, 1) → app (0.25, 0.625) · `a` (2.64, 2) → app (0.5, 0.67) · `c` (3, 2) → app (0.5, 0.625) · `e` (3.36, 2) → app (0.5, 0.58)

**Đặt bi:** bi mục tiêu cố định ở (3, 1). Bi cái đặt lần lượt trên trục giữa W = 2 tại L = 2.64, 2.82, 3.0, 3.18, 3.36, tức 5 vị trí `a`–`e` cách nhau 1 bi. Sơ đồ chỉ vẽ `a`, `c`, `e` vì lưới quá thô. Vị trí giữa `c` thẳng hàng với bi mục tiêu.

**Cách đánh:** bank bật long rail trái vào lỗ giữa SR từ mỗi vị trí. Khi bi cái lệch sang hai bên, cú bank có góc cắt nên bi mục tiêu bị cut-induced spin, phải bù điểm ngắm.

**Đạt khi:** 1 điểm mỗi vị trí, tối đa 5 [nguồn]. Hạng D đạt 3/5 [đề xuất].

### 70 · R5 Soft Break from the Box

**Hạng F** · Break nhẹ hợp lệ · Bob Jewett, BD 09/2008

      0   1   2   3   4   5   6   7   8  L
     @----+---+---+---@---+---+---+----@
  W0 |                                 |
     |                                 |
  W1 | *      *                        |
     |                                 |
  W2 |    C   .       .      19 R      |
     |                                 |
  W3 | *      *                        |
     |                                 |
  W4 |                                 |
     @----+---+---+---@---+---+---+----@
```

**Đặt bi:** rack 9-ball với bi 9 trên foot spot (6, 2), bi 1 ở đỉnh (5.69, 2). Bi cái đặt trong box ở nửa giữa kitchen: L ≤ 2, W 1 → 3. Bốn góc box là các dấu `*`.

**Đạt khi:** break hợp lệ khi ít nhất 3 bi vượt qua head string [nguồn]. Cộng điểm nếu vào bi và còn cú tiếp. Hạng F đạt 7/10 break hợp lệ [đề xuất].

### 71 · R1 Break Evaluation

**Hạng D** · Break 9-ball chấm 5 tiêu chí · Billiard University Exam II, S10

```text
      0   1   2   3   4   5   6   7   8  L
     @----+---+---+---@---+---+---+----@
  W0 |        *               *        |
     |                                 |
  W1 |                                 |
     |                                 |
  W2 |    C   .       .       19R      |
     |                                 |
  W3 |                                 |
     |                                 |
  W4 |        *               *        |
     @----+---+---+---@---+---+---+----@
```

**Đặt bi:** rack 9-ball thật chặt, bi 1 trên foot spot (6, 2). Bi cái in hand ở bất cứ đâu sau head string (L ≤ 2). Zone là dải giữa bàn L 2 → 6, hết bề ngang.

**Cách đánh:** break 3 lần. Mỗi lần cộng 1 điểm cho từng tiêu chí đạt:
1. Không scratch.
2. Không scratch và bi cái không chạm băng.
3. Không scratch và tâm bi cái nằm trong zone suốt cú break.
4. Không scratch và vào ít nhất 1 bi.
5. Không scratch và có ít nhất 3 bi vào lỗ hoặc vượt qua head string.

**Đạt khi:** lấy median của 3 lần (bỏ lần cao nhất và thấp nhất), tối đa 5 [nguồn]. Hạng D đạt 3/5 [đề xuất].

**Nguồn:** https://billiarduniversity.org/documents/BU_Exam-II_Skills-Masters.pdf · https://drdavepoolinfo.com/bd_articles/2014/may14.pdf — luật [nguồn]. Hai nguồn diễn đạt tiêu chí 3 hơi lệch; em lấy PDF làm chuẩn.

     @----+---+---+---@---+---+---+----@
  W0 |                               x |
     |                                 |
  W1 |                                 |
     |                                 |
  W2 |        .       .       .        |
     |        o                        |

     |                                 |
  W4 |                                 |
     @----+---+---+---@---+---+---+----@
```

Toạ độ (L, W) → app (x, y): `C` (1, 3) → app (0.75, 0.875) · `o` (1.93, 2.43) → app (0.608, 0.759) · `o` (2.07, 2.77) → app (0.693, 0.741) · `x` (7.8, 0.15) → app (0.037, 0.025)

**Đạt khi:** 3 lượt, 1 điểm mỗi lần vào mà không chạm bi chắn. Scratch vẫn tính điểm [nguồn]. Hạng C đạt 2/3 [đề xuất]. Bản Masters dùng 1 bi chắn, 5 lượt.

     @----+---+---+---@---+---+---+----@
  W0 |                       Co      1 |
     |                                 |
  W1 |                                 |
     |                                 |
  W2 |        .       .       .        |
     |                                 |
  W3 |                                 |

  W4 |                                 |
     @----+---+---+---@---+---+---+----@
```

Toạ độ (L, W) → app (x, y): `1` (7.85, 0.12) → app (0.03, 0.019) · `o` (6, 0.09) → app (0.022, 0.25) · `C` (5.64, 0.18) → app (0.045, 0.295)

**Đặt bi:** bi 1 ở miệng lỗ FL (7.85, 0.12). Bi chắn ép long rail trái tại chỗ đánh dấu bằng đồng xu, ví dụ (6, 0.09). Bi cái cách băng nửa bi và cách bi chắn khoảng 1 bi: (5.64, 0.18).

**Nguồn:** http://www.sfbilliards.com/articles/2003.pdf — luật [nguồn]; toạ độ [suy luận].

## Bài kiểm tra chạy bàn (74–81)

Luật chung của RDS (Runout Drill System, BU Exam IV) [nguồn]:
- Mỗi level bắt đầu bằng break, sau đó ball in hand. Trượt hoặc scratch sau break là hết lượt.
- Scratch lúc break không bị phạt.
- Luật WPA, chỉ tính foul bi cái.
- Rack rotation thì combo và slop được tính. Rack 8-ball và 14.1 phải gọi bi.
- Chạy được 2/3 rack thì lên level, 1/3 thì giữ, 0/3 thì xuống.
- Biến thể RDS 100: bắt đầu từ 100 điểm, mỗi level một rack, trừ số bi còn trên bàn khi trượt.

Nguồn RDS: https://billiarduniversity.org/documents/BU_Exam-IV_Runout_Drill_System.pdf

### 80 · 10-Ball Ghost

**Hạng B** · Chạy 10-ball với "ghost" · Joe Tucker, AZB

```text
      0   1   2   3   4   5   6   7   8  L
     @----+---+---+---@---+---+---+----@
  W0 |                                 |
     |                                 |
  W1 |                                 |
     |                                 |
  W2 |    C   .       .       .R       |
     |                                 |
  W3 |                                 |
     |                                 |
  W4 |                                 |
     @----+---+---+---@---+---+---+----@
```

**Đặt bi:** rack 10-ball, break.

**Cách đánh:** chơi 10-ball với "ghost". Ghost thắng mọi rack anh không chạy hết. Cách tính điểm chi tiết em chưa lấy được. Em đoán là 1 điểm mỗi bi qua 10 rack, tối đa khoảng 100 [suy luận].

**Đạt khi:** thang của qghunter (2009): Pro 70+, Semi-pro 60–69, A 50–59, **B 40–49**, C 30–39, D 20–29 [forum]. Có một thang chi tiết hơn trong snippet nhưng chưa kiểm được và lệch với thang này: 30–35 D+, 36–40 C, 41–45 C+, 46–50 B, 51–55 B+, 56–60 A. Em dùng thang qghunter.

Biến thể 15-ball ghost: điểm là số lần ball in hand phải dùng qua 10 rack, thấp là tốt. 0–20 Pro, 21–40 A, 41–60 B, 61–80 C, 81–100 D [forum].
