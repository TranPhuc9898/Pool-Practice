# Drills 32–48 — Đưa bi

Quy ước toạ độ, ký hiệu và cách quy đổi sang app nằm ở [00-index.md](00-index.md). Tóm tắt: `(L, W)` tính bằng diamond, L từ head rail (0) tới foot rail (8), W từ long rail trái (0) tới long rail phải (4), đứng ở head nhìn về foot. `C` bi cái, `1`–`9` bi số, `x` bi mục tiêu, `a`–`g` các vị trí bi cái, `o` bi chắn hoặc bi phụ, `*` đích.

### 32 · 10 Straight-In in a Row

**Hạng G** · Thẳng lỗ, stroke · Dr. Dave, BD 05/2020 #3

```text
      0   1   2   3   4   5   6   7   8  L
     @----+---+---+---@---+---+---+----@
  W0 |                                 |
     |                                 |
  W1 |                        x        |
     |                                 |
  W2 |        .       .C      .        |
     |                                 |
  W3 |                                 |
     |                                 |
  W4 |                                 |
     @----+---+---+---@---+---+---+----@
```

Toạ độ (L, W) → app (x, y): `C` (4.21, 1.89) → app (0.472, 0.474) · `x` (6, 1) → app (0.25, 0.25)

**Đặt bi:** bi mục tiêu ở (6, 1), bi cái lùi 2 diamond trên đường nối lỗ FL qua bi mục tiêu, cú thẳng lỗ hoàn toàn. Đánh dấu hai chỗ bằng vòng giấy để đặt lại y hệt.

**Cách đánh:** đánh tâm, lực vừa, cho bi cái dừng (stop) tại chỗ chạm. Mỗi cú đặt lại đúng vị trí. Giữ người yên tới khi bi rơi.

**Đạt khi:** vào 10 cú liên tiếp. Trượt thì đếm lại từ 0.

**Nguồn:** https://drdavepoolinfo.com/bd_articles/2020/may20.pdf — tiêu chí 10 liên tiếp [nguồn]; nguồn không cho toạ độ, vị trí trên là [đề xuất]. Dr. Dave ghi: không vào nổi 10 liên tiếp thì nên nhờ instructor.

### 33 · Short Stop / Follow / Draw into Side

**Hạng G** · Thẳng lỗ, stroke ngắn · Dr. Dave, BD 05/2020 #6

```text
      0   1   2   3   4   5   6   7   8  L
     @----+---+---+---@---+---+---+----@
  W0 |                                 |
     |                                 |
  W1 |                x                |
     |                                 |
  W2 |        .       C       .        |
     |                                 |
  W3 |                                 |
     |                                 |
  W4 |                                 |
     @----+---+---+---@---+---+---+----@
```

Toạ độ (L, W) → app (x, y): `C` (4, 2) → app (0.5, 0.5) · `x` (4, 1) → app (0.25, 0.5)

**Đặt bi:** bi cái ở center (4, 2), bi mục tiêu ở (4, 1), thẳng vào lỗ giữa SL.

**Cách đánh:** ba bài, mỗi bài làm tới khi đạt rồi chuyển:
1. Stop: bi cái đứng yên tại chỗ chạm.
2. Follow: bi cái lăn theo vào cùng lỗ SL.
3. Draw: kéo bi cái về thẳng lỗ giữa đối diện SR.

**Đạt khi:** mỗi bài 5 cú liên tiếp.

**Nguồn:** https://drdavepoolinfo.com/bd_articles/2020/may20.pdf — layout và tiêu chí [nguồn].

### 34 · Ring Around the Side

**Hạng G** · Lỗ giữa nhiều góc · Mosconi, Jewett BD 01/2010

```text
      0   1   2   3   4   5   6   7   8  L
     @----+---+---+---@---+---+---+----@
  W0 |                                 |
     |            1       5            |
  W1 |             2  3  4             |
     |                                 |
  W2 |        .       C       .        |
     |                                 |
  W3 |                                 |
     |                                 |
  W4 |                                 |
     @----+---+---+---@---+---+---+----@
```

Toạ độ (L, W) → app (x, y): `1` (3, 0.3) → app (0.075, 0.625) · `2` (3.3, 0.8) → app (0.2, 0.588) · `3` (4, 1) → app (0.25, 0.5) · `4` (4.7, 0.8) → app (0.2, 0.412) · `5` (5, 0.3) → app (0.075, 0.375) · `C` (4, 2) → app (0.5, 0.5)

**Đặt bi:** 5 bi xếp nửa vòng tròn bán kính khoảng 1 diamond quanh lỗ SL. Bi cái ball in hand cho cú đầu.

**Cách đánh:**
- Bản G: ball in hand mỗi cú, vào lần lượt 1 → 5 vào SL.
- Bản gốc: chỉ ball in hand cú đầu, sau đó đánh từ chỗ bi cái dừng, chỉ dùng draw, bi cái không được chạm băng.

**Đạt khi:** bản G vào 5/5 hai lượt liền [đề xuất]. Bản gốc chạy hết 5 bi là lên F.

**Nguồn:** https://www.sfbilliards.com/articles/2010.pdf — luật [nguồn]; bán kính và toạ độ 5 bi [suy luận]. PAT-1 có chấm điểm bài này nhưng thang không lấy được.

### 35 · 15-Ball Lineup

**Hạng G** · Thẳng lỗ, stop · Scott Lee

```text
      0   1   2   3   4   5   6   7   8  L
     @----+---+---+---@---+---+---+----@
  W0 |                                 |
     |                x                |
  W1 |                1                |
     |        C       x                |
  W2 |        .       x       .        |
     |                x                |
  W3 |                x                |
     |                x                |
  W4 |                                 |
     @----+---+---+---@---+---+---+----@
```

**Đặt bi:** 15 bi xếp ngang bàn trên đường nối hai lỗ giữa (L = 4), W chia đều từ 0.3 tới 3.7. Sơ đồ chỉ vẽ đại diện. Với mỗi bi, bi cái đặt thẳng lỗ về một góc foot, lùi 2 diamond. Ví dụ bi `1` ở (4, 1) vào FL thì bi cái ở (2.06, 1.49).

**Cách đánh:** stop shot. Bi 1–8 vào FL, bi 9–15 vào FR. Bi trượt thì bỏ ra ngoài, không đánh lại.

**Đạt khi:**
- G: từ 10/15 trở lên với bi cái lùi 1 diamond, rồi lên 2 diamond [đề xuất].
- Mốc cộng đồng: 12–13/15 là "dưới intermediate một chút", khoảng 95% là intermediate [forum].
- Nâng cao: bi cái ở diamond đầu tiên hoặc sát end rail [nguồn].

**Nguồn:** https://www.mypoolblog.com/lessons-and-articles/15-ball-lineup-drill [nguồn] · benchmark https://forums.azbilliards.com/threads/your-percent-for-this-drill.503614/ [forum].

### 36 · Jewett Spot Progression

**Hạng G** · Ngắm cắt tăng dần, đo điểm 50% · Bob Jewett, Progressive Practice Fig. 2

```text
      0   1   2   3   4   5   6   7   8  L
     @----+---+---+---@---+---+---+----@
  W0 |                                 |
     |                                 |
  W1 |    e   d   c   b   a            |
     |                                 |
  W2 |    f   .       .       x        |
     |                                 |
  W3 |    g                            |
     |                                 |
  W4 |                                 |
     @----+---+---+---@---+---+---+----@
```

Toạ độ (L, W) → app (x, y): `x` (6, 2) → app (0.5, 0.25) · `a` (5, 1) → app (0.25, 0.375) · `b` (4, 1) → app (0.25, 0.5) · `c` (3, 1) → app (0.25, 0.625) · `d` (2, 1) → app (0.25, 0.75) · `e` (1, 1) → app (0.25, 0.875) · `f` (1, 2) → app (0.5, 0.875) · `g` (1, 3) → app (0.75, 0.875)

**Đặt bi:** bi mục tiêu trên foot spot (6, 2), đích là lỗ FR. Bi cái đi trên đường W = 1 (cách long rail 1 diamond): vị trí `a`–`e` lùi dần từ L = 5 về L = 1, rồi `f`, `g` rẽ góc chạy ngang theo head rail. Vị trí `a` là cú thẳng lỗ; góc cắt tăng dần tới khoảng 56° ở `g` [suy luận hình học].

**Cách đánh:** bắt đầu ở `a`. Vào thì lùi bi cái 1 vị trí (khó hơn), trượt thì tiến lại 1 vị trí. Đánh 15 cú, ghi vị trí cuối. Muốn mịn hơn thì chia nấc ½ diamond.

**Đạt khi:** vị trí cuối chính là điểm 50% của anh. Người trên trung bình rẽ được góc ở vị trí 5 (`e`) [nguồn]. Bản "67%": trượt lùi 2 nấc, vào tiến 1 nấc, dùng khi muốn đo mức chắc tay hơn.

**Nguồn:** https://drdavepoolinfo.com/resource_files/progpract.pdf — luật và mốc [nguồn]; toạ độ từng vị trí [suy luận], cần đối chiếu hình gốc.

     @----+---+---+---@---+---+---+----@

Toạ độ (L, W) → app (x, y): `C` (0.5, 3.75) → app (0.938, 0.938) · `x` (4.25, 1.9) → app (0.475, 0.469)

**Đặt bi:** bi cái ở (0.5, 3.75) gần góc HR, bi mục tiêu ở (4.25, 1.9) nằm giữa bi cái và lỗ FL, trên đường chéo bàn. Đánh dấu bằng donut sticker.

### 38 · BU F1 Cut Progression

**Hạng F** · Cắt tăng dần một phía · Billiard University Exam I, F1

```text
      0   1   2   3   4   5   6   7   8  L
     @----+---+---+---@---+---+---+----@
  W0 |                                 |
     |                                 |
  W1 |                               x |
     |                                 |
  W2 |        .       .       .        |
     |                                 |
  W3 |    g   f   e   d   c   b   a    |
     |                                 |
  W4 |                                 |
     @----+---+---+---@---+---+---+----@
```

Toạ độ (L, W) → app (x, y): `x` (7.7, 1) → app (0.25, 0.037) · `a` (7, 3) → app (0.75, 0.125) · `b` (6, 3) → app (0.75, 0.25) · `c` (5, 3) → app (0.75, 0.375) · `d` (4, 3) → app (0.75, 0.5) · `e` (3, 3) → app (0.75, 0.625) · `f` (2, 3) → app (0.75, 0.75) · `g` (1, 3) → app (0.75, 0.875)

**Đặt bi:** bi mục tiêu cách foot rail một khe đúng một bi, cách góc FL khoảng 1 diamond: (7.7, 1). Bi đi dọc foot rail vào FL. Bi cái trên đường W = 3, vị trí 1–7 (`a`–`g`) ở L = 7 → 1. Góc cắt tăng dần theo vị trí.

**Cách đánh:** bắt đầu ở vị trí 4 (`d`). Vào thì lùi 1 vị trí, trượt thì tiến 1 vị trí. 10 cú. Scratch không bị phạt. Làm thêm bản mirror cho cắt hướng ngược.

**Đạt khi:** điểm = vị trí cuối + 1 điểm thưởng cho mỗi cú vào ở vị trí 7, tối đa 10 [nguồn]. Hạng F đạt từ 5 [đề xuất].

**Nguồn:** https://billiarduniversity.org/documents/BU_Exam-I_Fundamentals.pdf — luật [nguồn]; toạ độ [suy luận, đo từ hình], sai số khoảng ±¼ diamond.

**Đặt bi:** hai chỗ đặt bi cái `a` (2, 1) và `b` (2, 3). Bốn chỗ đặt bi mục tiêu: `1` (3, 1), `2` (3, 3), center `3` (4, 2), foot spot `4` (6, 2). Mỗi cú chỉ đặt một bi.

| 3 | `a` | `4` | FR |
| 4 | `a` | `3` | SR |
| 5 | `a` | `3` | FR |

| 9 | `b` | `3` | SL |
| 10 | `b` | `3` | FL |

**Đạt khi:** điểm = số cú vào, tối đa 10. Scratch tính là hỏng. Hạng F đạt từ 7/10 [đề xuất].

**Nguồn:** https://billiarduniversity.org/documents/BU_Exam-I_Fundamentals.pdf — danh sách cú [nguồn]; toạ độ [suy luận, đo từ hình].

### 40 · Ride the Rails

**Hạng F** · Bi gần băng, chạy bàn 8-ball · Larry Schwartz, Billiards Digest

```text
      0   1   2   3   4   5   6   7   8  L
     @----+---+---+---@---+---+---+----@
  W0 |                                 |
     |        3               4        |
  W1 |                                 |
     |                                 |
  W2 | 1      .       .       .      2 |
     |                                 |
  W3 |                                 |
     |        5               8        |
  W4 |                                 |
     @----+---+---+---@---+---+---+----@
```

Toạ độ (L, W) → app (x, y): `1` (0.27, 2) → app (0.5, 0.966) · `2` (7.73, 2) → app (0.5, 0.034) · `3` (2, 0.27) → app (0.068, 0.75) · `4` (6, 0.27) → app (0.068, 0.25) · `5` (2, 3.73) → app (0.932, 0.75) · `8` (6, 3.73) → app (0.932, 0.25)

**Đặt bi:** 5 bi trơn và bi 8, mỗi bi ở giữa một đoạn băng, cách băng đúng một bề rộng bi (tâm cách băng khoảng 0.27 diamond).

**Cách đánh:** ball in hand cú đầu, chạy bàn kiểu 8-ball: 5 bi trơn theo thứ tự tuỳ ý, gọi lỗ, rồi bi 8. Chạy được thì dời các bi sát băng hơn, cuối cùng là ép băng.

**Đạt khi:** hạng F được thêm 1 lần ball in hand giữa chừng; chạy hết 3/5 lượt là đạt [đề xuất]. Không dùng ball in hand thêm mà vẫn chạy được thì lên E.

**Nguồn:** http://www.billiardsdigest.com/showdrill.php?id=16 — luật [nguồn]; 6 đoạn băng [suy luận]; tiêu chí [đề xuất].

### 42 · The Ladder

**Hạng E** · Cắt bi sát băng kèm position dọc băng · Feijen / Kinister, bản 12 bi

```text
      0   1   2   3   4   5   6   7   8  L
     @----+---+---+---@---+---+---+----@
  W0 |    x x     x       x     x x    |
     |                                 |
  W1 |                                 |
     |                                 |
  W2 |        .       .       .        |
     |                                 |
  W3 |                                 |
     |                                 |
  W4 |    x x     x       x     x x    |
     @----+---+---+---@---+---+---+----@
```

**Đặt bi:** 4 cụm 3 bi, mỗi cụm ứng với một góc. Bi cách long rail một bề ngang ngón cái (tâm cách băng khoảng 0.15 diamond), ở diamond thứ 1, 1.5 và 3 tính từ góc đó. Ví dụ cụm FL: (7, 0.15), (6.5, 0.15), (5, 0.15).

**Đạt khi:** đếm số bi liên tiếp. E: 4 bi; C: 8 bi; chạy hết 12 là mức A [đề xuất]. Người đăng bài tập 6–8 năm mà chạy hết 12 bi chưa tới 10 lần [forum].

**Nguồn:** https://forums.azbilliards.com/threads/the-ladder.37742 — layout và luật [forum]; toạ độ [suy luận]; mốc E/C/A [đề xuất].

**Đặt bi:** 15 bi ép băng: long rail tại L = 1, 2, 3, 5, 6, 7 trên cả hai long rail (12 bi), cộng foot rail tại W = 1, 2, 3 (3 bi). Bỏ head rail để đủ 15 bi [suy luận].

**Cách đánh:** ball in hand cú đầu, sau đó đánh từ chỗ bi cái dừng. Thứ tự tuỳ ý. Hết lượt khi chạm bi khác, trượt hoặc scratch.

**Đạt khi:** đếm bi liên tiếp. E đạt từ 5 bi [đề xuất]. Forum gợi ý tập liền 1 tiếng.

**Nguồn:** https://forums.azbilliards.com/threads/the-best-pool-drill.57129 — luật [forum]; chọn 15 vị trí [suy luận].

### 44 · Tom Ross Rail Shot

**Hạng E** · Bi gần băng và ép băng, rail-first có english · Tom Ross, CueTimes 2000

```text
      0   1   2   3   4   5   6   7   8  L
     @----+---+---+---@---+---+---+----@
  W0 |                                 |
     |                          b  a   |
  W1 |                        c        |
     |                                 |
  W2 |        .       .       .      x |
     |                                 |
  W3 |                                 |
     |                                 |
  W4 |                                 |
     @----+---+---+---@---+---+---+----@
```

Toạ độ (L, W) → app (x, y): `x` (7.87, 2.2) → app (0.55, 0.016) · `a` (7.2, 0.7) → app (0.175, 0.1) · `b` (6.5, 0.7) → app (0.175, 0.188) · `c` (5.95, 1.05) → app (0.263, 0.256)

**Đặt bi:** bi mục tiêu cách foot rail ½ inch, gần giữa foot rail: (7.87, 2.2). Cắt dọc foot rail vào FR. Ba chỗ bi cái `a`, `b`, `c`. Góc cắt khoảng 27° từ `a`, khoảng 60° từ `c` [suy luận].

**Cách đánh:**
1. Bi cách băng ½ inch: ngắm cho bi mục tiêu chạy song song băng, chạm mép băng long rail ở miệng lỗ, không ngắm tâm lỗ. Cắt dày hơn một chút để bù cling và throw. Đánh từ `a`, `b`, `c`.
2. Ép bi sát băng (L = 7.91), đánh từ `a` rồi `b`. "Chơi như không có băng."
3. Góc trên 45° (`b`, `c`): đánh rail-first, english mạnh cùng phía hướng cắt. Bi cái chạm băng ngay sát bi mục tiêu rồi spin kéo vào điểm tiếp xúc.

**Đạt khi:** mỗi chỗ 7/10 [đề xuất]. Tom Ross nói ai cũng nắm được kỹ thuật rail-first "trong 15 phút hoặc ít hơn".

### 46 · Jal Circle

**Hạng E** · Liên hệ độ dày (fraction of ball) với góc cắt · Jal, AZB

```text
      0   1   2   3   4   5   6   7   8  L
     @----+---+---+---@---+---+---+----@
  W0 |                                 |
     |                1                |
  W1 |                 2               |
     |                 3               |
  W2 |        . C     . 4     .        |
     |                    5            |
  W3 |                     6           |
     |                        7        |
  W4 |                                 |
     @----+---+---+---@---+---+---+----@
```

Toạ độ (L, W) → app (x, y): `1` (4.03, 0.5) → app (0.125, 0.496) · `2` (4.13, 1) → app (0.25, 0.484) · `3` (4.29, 1.5) → app (0.375, 0.464) · `4` (4.54, 2) → app (0.5, 0.432) · `5` (4.88, 2.5) → app (0.625, 0.39) · `6` (5.35, 3) → app (0.75, 0.331) · `7` (6.06, 3.5) → app (0.875, 0.243) · `C` (2.54, 2) → app (0.5, 0.682)

**Đặt bi:** các bi nằm trên cung tròn tâm lỗ FL, bán kính 4 diamond (nửa chiều dài bàn), chạy từ lỗ giữa SL tới góc FR. 7 bi tại W = 0.5, 1, …, 3.5. Bi cái đặt sau bi mục tiêu, cùng W, lùi 1–2 diamond về phía head, đánh song song long rail. Ví dụ bi 4 với bi cái `C`.

**Cách đánh:** đánh từng bi vào FL. Quy tắc của Jal: độ dày = 1 − W/4. Bi 1 dày ⅞, bi 2 dày ¾, bi 4 dày ½, bi 7 dày ⅛. Em kiểm bằng hình học: với cách đặt này, sin(góc cắt) = W/4, khớp với quy tắc. Biến thể: dời cả cung lên 1 diamond.

**Đạt khi:** mỗi bi 4/5 trước khi sang bi kế [đề xuất]. Forum không đưa tiêu chí.

**Nguồn:** https://forums.azbilliards.com/threads/shot-making-drills.56705 — cung và quy tắc [forum]; cách đặt bi cái song song băng [suy luận, kiểm bằng hình học].
